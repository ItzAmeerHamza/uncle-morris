# Call Uncle Morris (prototype)

Next.js template for the comic-style local × product page from the Uncle Morris manifesto.

## Run

```bash
cd uncle-morris
npm install
npm run dev
```

Open:

- http://localhost:3000
- http://localhost:3000/california/los-angeles/encino/dscr-loans
- http://localhost:3000/florida/miami-dade/miami/bank-statement-loans

Same layout, different Airtable-style records in `lib/pages.ts`. Snapshot numbers are labeled sample data on purpose.
